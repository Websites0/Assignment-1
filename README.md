# Assignment 1 - Cool Dark UI Template

A web page template designed for Webflow Agencies, featuring a bold dark UI theme. This project is a static website built with HTML and CSS.

## Description

This template includes several key sections:
- **Header**: Navigation bar and hero section with a call to action.
- **Action**: A section highlighting the product in action.
- **Product Stats**: Displaying user statistics like active users and satisfaction rate.
- **User Testimonials**: A section for user reviews and ratings.

The design utilizes **Inter** and **Raleway** fonts from Google Fonts.

## Project Structure

The file structure of the project is as follows:

```
.
├── index.html   # Main HTML file containing the page structure
├── styles.css   # CSS file containing styles and layout definitions
└── README.md    # Project documentation
```

> **Note**: The HTML and CSS files reference an `Assets/` directory for images (e.g., `Assets/Hero-bg.png`, `Assets/wc-mini.png`, `Assets/icon-star.png`). Ensure this directory exists and contains the necessary images for the template to render correctly.

## Usage

To view the project:
1. Clone or download the repository.
2. Open the `index.html` file in any modern web browser.
